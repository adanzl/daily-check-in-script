# DailyCheckIn

基于 Docker、青龙面板、群晖或本地运行的每日签到脚本。

本仓库 fork 自 [Sitoi/dailycheckin](https://github.com/Sitoi/dailycheckin)。

## 特性

- 支持 PyPI 包安装
- 支持多个平台部署
- 支持多个平台签到
- 支持多个平台通知
- 支持多个账号签到
- 支持定时任务
- 支持项目自动更新
